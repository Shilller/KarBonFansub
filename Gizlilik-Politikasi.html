Gizlilik Politikası

Son güncelleme: 15 Mayıs 2026

1. Genel Bilgilendirme

Bu web sitesi (karbonfansub.com), GitHub Pages üzerinde barındırılan statik bir web sitesidir. Kullanıcı gizliliği önemlidir ve bu sayfa bilgilendirme amacıyla hazırlanmıştır.

2. Veri Toplanması

Bu site doğrudan kullanıcıdan kişisel veri toplamaz. Üyelik, giriş sistemi veya form gibi veri giriş alanları bulunmamaktadır.

  • Kullanıcı hesabı veya kayıt sistemi yoktur
  • İsim, e-posta veya benzeri kişisel veri toplanmaz
  • Sunucu taraflı veri kaydı tutulmaz (statik GitHub Pages yapısı nedeniyle)

3. Disqus Yorum Sistemi

Sitede yorum sistemi olarak Disqus kullanılmaktadır. Disqus, kendi gizlilik politikası kapsamında kullanıcı bilgilerini (isim, e-posta ve teknik veriler gibi) işleyebilir. Bu veriler Disqus tarafından yönetilir sitemizin bu konuda herhangi bir sorumluluğu yoktur.

4. Çerezler (Cookies)

Bu web sitesi doğrudan çerez (cookie) kullanmaz. Ancak Disqus gibi üçüncü taraf servisler kendi çerezlerini kullanabilir.

5. Üçüncü Taraf Servisler

Site içerisinde Disqus gibi üçüncü taraf hizmetler kullanılabilir. Bu hizmetlerin veri kullanımı kendi gizlilik politikalarına tabidir.

6. GitHub Pages Yapısı

Site GitHub Pages üzerinde barındırıldığı için GitHub tarafından sistemsel erişim logları tutulabilir. Bu veriler site sahibi tarafından kişisel olarak analiz edilmez.

7. Güvenlik

Site statik yapıda olduğu için sunucu taraflı veri işleme yapılmaz. Ancak internet ortamında hiçbir sistem %100 güvenli değildir.

8. KVKK Bilgilendirmesi

Bu site kapsamında KVKK (Kişisel Verilerin Korunması Kanunu) çerçevesinde doğrudan kullanıcı verisi toplanmaz veya işlenmez. Ancak Disqus gibi üçüncü taraf servisler kendi politikaları kapsamında veri işleyebilir.

9. Bağlantılar

Sitede yer alan dış bağlantılar farklı web sitelerine yönlendirebilir. Bu sitelerin içeriklerinden, güvenliğinden veya gizlilik uygulamalarından site yönetimi sorumlu değildir.

10. İletişim

Gizlilik politikası ile ilgili sorular için discord üzerinden bizimle iletişime geçebilirsiniz.
